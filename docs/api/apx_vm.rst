APX Virtual Machine (apx_vm)
============================

The ``apx_vm`` module implements a high-performance bytecode interpreter for serializing and deserializing APX port values according to the APX VM 2.1 standard.

Overview
--------

The APX VM executes compact bytecode instructions generated by the APX compiler:

* **Packing**: Serializes dynamic data structures (:c:type:`dtl_dv_t`) into raw packed wire formats.
* **Unpacking**: Deserializes raw incoming byte streams into dynamic values.
* Eliminates the need for generated C serialization code.
