Core Types and Definitions (apx_types)
======================================

The ``apx_types`` module defines fundamental types, identifiers, port directions, and configuration limits used throughout the APX library.

Overview
--------

Defines port identifiers (``apx_port_id_t``), type IDs (``apx_type_id_t``), size types (``apx_size_t``), and base data structures.
